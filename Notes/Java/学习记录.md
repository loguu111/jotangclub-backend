## 对 Java 面向对象的理解

完成本项目后与第一学期 c 语言完成的 PBLF 对比，本人更深刻的感受到 Java 面向对象，c 面向过程的特点  

c 的项目是确切由主函数进入，调用其他函数（这些函数可能在同一文件或别的文件中），最终在主函数结束运行程序，感觉类似于构造一个环状结构。Java 的项目则更像构造一个网，我们关注的是数据从某一个接口进入（POST,PUT）或出来 （DELETE,GET）的过程。

# 包

## controller 注解 @RestController

这是后端代码信息进入的地方，controller 接收网页的代码，然后通过调用方法将信息分发下去。类似与 Java 我们手写的这张网状结构的起始点，通过识别增删改查来把信息分发给后面的 service。  

## service 注解 @Component/@Service

service 部分主要是 Java 程序逻辑进行的部分。相比起 controller 要接受 spring boot 的信息，mapper 要操作 MySQL ，service与网站的交流相对最少，因此也是注解最少的部分。也因此，service 可以完全注重于数据的复杂处理，这也是 Java 最面向过程的部分。

## mapper 注解 @mapper

mapper 部分是与数据库交互的部分，这里通常只定义接口，然后由 xml 实现操作数据库
