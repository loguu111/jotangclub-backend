## 对 Java 面向对象的理解

完成本项目后与第一学期 c 语言完成的 PBLF 对比，本人更深刻的感受到 Java 面向对象，c 面向过程的特点  

c 的项目是确切由主函数进入，调用其他函数（这些函数可能在同一文件或别的文件中），最终在主函数结束运行程序，感觉类似于构造一个环状结构。Java 的项目则更像构造一个网，我们关注的是数据从某一个接口进入（POST,PUT）或出来 （DELETE,GET）的过程。

# 包

## controller 注解 @RestController

这是后端代码信息进入的地方，controller 接收网页的代码，然后通过调用方法将信息分发下去。类似与 Java 我们手写的这张网状结构的起始点，通过识别增删改查来把信息分发给后面的 service。  

## service 注解 @Component/@Service

service 部分主要是业务逻辑进行的地方。controller 要接收请求、mapper 要操作 MySQL，而 service 既不和网站直接打交道、也不直接写 SQL，只专注于处理数据。

它的情况比较特别：**类上的注解最多**（9 个类全都带 @Service 或 @Component），但**方法上几乎没有注解**（整个 service 包只有 @Transactional 和 @RabbitListener 这 3 处）——因为类交给 Spring 管好之后，方法就是普通的方法调用，不需要再标什么。相比之下 controller 的每个方法都得标 @GetMapping / @PostMapping。

因此 service 可以完全专注于数据的复杂处理。虽然里面写的是一步一步的流程，但这些步骤都是通过调用别的对象完成的（依赖注入），所以它仍然是面向对象的。
