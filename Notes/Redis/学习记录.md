## 问题回答  

### 1：Redis 为什么这么快?  

1.Redis 的数据放在内存中，比放在磁盘的 MySQL 快  

2.其底层数据结构是哈希表，查询复杂度只有常数级  

3.单线程模型，Redis 对命令的执行极快，因此比起占用CPU多线程执行命令，单线程模型反而避免锁竞争和上下文切换，使得执行更快  

4.Redis使用了 IO 多路复用，单线程也能处理大量并发连接  

### 2：在 MySQL 中的一行数据, 你可以以什么样的形式存到 Redis 中作为缓存?  

用 key （如笔记的ID）和一个能代表该数据特征的字符串作 value 值存储  

### 3：如何使用你所选择的编程语言来通过代码操作 Redis?  

Java 语言通过 RedisTemplate 工具来操作 Redis
